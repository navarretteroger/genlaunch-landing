Privacy notice

Preview mode: this form does not store your email and does not provide a real PDF download. Production stays off until a real backend, a verified deletion contact, and a controlled website download exist.

A verified deletion contact is not published on this page. Capture stays off until the owner configures one. This page does not invent an address.

When production capture is on, the server stores the email address you submit. It also stores a signup id, the UTC time, the source label genlaunch-landing, privacy notice version 2026-11-06, and marketing_opt_in set to false.

The purpose of storing the email is guide access. This form does not ask for a marketing choice. marketing_opt_in is stored as false. That false value is not consent to messages.

This system does not send email and does not track email opens. Outbound sending is off. Saving an email address does not prove you control that inbox. The check in the browser is only a format check.

A download token works for anyone who has it until it expires. The default lifetime is 15 minutes. It is not a link to the private Drive file. The guide is not emailed.

The signup row is stored in a private Google Sheet in the site owner’s Google account. This page is hosted on GitHub Pages. The capture API runs on a host the owner chooses. Those providers can keep their own connection logs. This API is written to log the HTTP method, path, and status, not the email address or the download token.

The signup sheet is separate from campaign prospect lists. No automatic deletion period is configured. The owner can delete a row by hand. This is not a retention guarantee or a certification.
