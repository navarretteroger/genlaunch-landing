Privacy notice

7 November 2026. Roger Navarrette publishes this page for the Customer Recovery guide.

What this site is

This is a static website hosted on GitHub Pages. It offers a signup form for a free guide. It does not have an account login, a payment form, or a place to upload your customer list.

The guide tells a shop owner how to look through their own CRM and stop at drafts. That work happens in the shop’s CRM. This website does not receive those records. If you later use an AI chat to walk through your CRM, that chat is not this website, and the guide says not to upload real customer details there.

What you can submit here

The signup form asks for an email address. It does not ask for a phone number, a name, or a separate promotions checkbox. The form is the SendFox form whose public id is 1xvkdn. SendFox adds the address to the Customer Recovery guide list.

Opening the signup form loads SendFox’s script from cdn.sendfox.com. When you send the form, that script can run Google invisible reCAPTCHA. The address is then sent to SendFox at sendfox.com.

The guide file

This website does not host the guide file. SendFox is the service that emails the guide. The file itself is hosted on Google Drive. This page does not link a specific file, because that file can be replaced.

SendFox may email you to confirm the address before it sends the guide message. This page does not show whether a message has arrived.

Other services that load

  • GitHub Pages hosts these files. GitHub’s privacy statement.
  • Google Fonts supplies the Poppins font from fonts.googleapis.com and fonts.gstatic.com. Google’s privacy policy.
  • SendFox runs the form and the guide email. SendFox’s privacy notice.
  • Google reCAPTCHA can run when the form is sent. Google’s privacy policy and Google’s terms.
  • Google Drive serves the guide file if you open or download it. Google’s privacy policy.

This site’s own files do not add an analytics product. SendFox’s script can store a small flag in this browser, such as whether the form was completed. SendFox and Google may also set cookies or similar storage when their scripts run. This notice does not list every cookie name, and it does not say the site is free of cookies.

Messages and unsubscribing

A message from SendFox can include its own unsubscribe control. This website does not have a separate unsubscribe form. This page does not state how long SendFox or Google keep an address.

Asking for a correction or deletion

This site does not publish an email address or phone number for a request to correct or delete an address. That is a gap. This page does not invent one. Unsubscribing from a SendFox message is a separate choice. It stops future messages. It is not a correction or deletion request.
