# genlaunch-landing

GenLaunch Customer Recovery guide landing page. Static HTML, CSS and JS, no build step.

- `index.html`: page content and the SendFox signup form (form 1xvkdn)
- `styles.css`: styles, including overrides for the SendFox form
- `main.js`: pop-up, sticky button and scroll effects

The guide page is `recover/index.html`. The site root is a short home page that links to it. `privacy.html` is the privacy notice. The guide file is not stored in this repository.

`CNAME` names `getgenlaunch.com`. Merging it tells GitHub Pages to use that domain. DNS is not changed by this file. Do not publish it until the domain is ready to point here.
